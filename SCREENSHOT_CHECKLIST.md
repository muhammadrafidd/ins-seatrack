# Checklist Screenshot Dokumentasi HKI

Gunakan screenshot beresolusi jelas, tanpa informasi pribadi atau token sesi. Simpan dengan format nama file di bawah agar mudah dilampirkan.

## Catatan penulisan before–after

- **Before:** jelaskan masalah awal, misalnya edit shipment muncul di bagian bawah halaman atau belum ada riwayat proses.
- **After:** jelaskan perbaikan, misalnya edit menggunakan pop-up, detail memiliki timeline, dan proses tersimpan sebagai riwayat.
- Tambahkan tanggal pengambilan screenshot serta versi aplikasi `v1.0.0` pada dokumen laporan HKI.
